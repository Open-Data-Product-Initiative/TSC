## 1. Start the release process for new specifications: ODPC, ODPG, and supporting vocabulary ODPV

The TSC reviewed the current status of the ODPS family expansion and agreed that the release process for the new specifications should start today.

The release scope includes:

* ODPC, Open Data Product Catalogs
* ODPG, Open Data Product Graphs
* ODPV, Open Data Product Vocabulary

These specifications extend the ODPS family from a single data product specification into a broader standards family for describing, cataloging, connecting, and interpreting data products.

The release process will follow the project release practices and include the required preparation of release candidate materials, documentation updates, repository updates, and public communication assets.

## 2. Start the release process for the AI Agent SDK

The TSC reviewed the plan for the AI-first oriented toolkit and agreed that the release process for the AI Agent SDK should start today.

The AI Agent SDK provides a Python-based toolkit for working with the Open Data Products standards family. It supports validation, document loading, explanation, reference traversal, CLI-based workflows, and MCP-based agent interaction.
